Рабочая папка - место где хранятся рабочие файлы
Индекс - промежуточное место между рабочими файлами и коммитом
Коммит - зафиксированная версия проекта в Git


Git - это программа на пк, для контроля версий
GitHub - это сервис для сохранения репозитория, совместной работы

git status - показывает статус git
git diff - показывает различия между сохраненными файлами и новыми до add
git diff --staged - показывает изменения которые уже добавлены в индекс
